# Source de vérité

Ce dossier contient **la vraie donnée** de l'atelier. Un agent qui rédige une proposition ou une vidéo vient chercher ici les chiffres, les prix, les noms et les références, au lieu de les deviner.

> Tout est **fictif** : la Brûlerie Caravelle, ses personnes, ses chiffres, nos clients de référence et nos tarifs ont été inventés pour l'atelier Klass. Ils sont cohérents entre eux, et c'est tout ce qui compte ici.

## Ce qu'on y trouve

| Dossier | Fichier | Ce qu'il contient |
|---|---|---|
| `client/` | `fiche-client.md` | Qui est la Brûlerie Caravelle : histoire, chiffres clés, produits, ton, personnes à connaître. La base de la vidéo. |
| `client/` | `brief-client.md` | Le message envoyé par la cliente pour demander une proposition. |
| `client/` | `notes-appel-2026-10-29.md` | Les notes de l'appel de découverte : besoins, budget, calendrier, objections. |
| `katalyx/` | `offres.md` | Ce que Katalyx propose : le périmètre de chaque offre. |
| `katalyx/` | `tarifs.md` | Nos prix et nos conditions. Aucun autre prix n'existe. |
| `katalyx/` | `references.md` | Nos projets passés, avec leurs résultats chiffrés. |
| `propositions-passees/` | `2025-03-fromagerie-dufresne-gagnee.md` | Une ancienne proposition **gagnée**, et pourquoi elle a gagné. |
| `propositions-passees/` | `2026-05-domaine-trois-chenes-perdue.md` | Une ancienne proposition **perdue**, et pourquoi elle a perdu. |

Les deux anciennes propositions servent à **calibrer la grille** : une bonne grille doit donner une meilleure note à la gagnée qu'à la perdue.

## La règle

**Ne devine pas, va chercher ici.** Si une information manque (un prix, une date, un chiffre), on ne l'invente pas : on écrit qu'elle manque, et on la demande.
