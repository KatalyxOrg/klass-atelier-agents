# Les prompt links de la séance

Pour le formateur. Tous les prompt links de l'atelier, au même endroit, dans l'ordre de la séance. On les colle dans le chat de la visio au moment où l'exercice commence. Les associés les retrouvent aussi dans la page support, `index.html`, à côté de chaque énoncé.

Chaque lien porte :
- `repo=KatalyxOrg/klass-atelier-agents` : le brouillon s'ouvre dans le projet de l'atelier. Si l'associé ne l'a pas encore (c'est le cas au lien d'accueil), T3 Code lui propose **Clone**, qui récupère la branche par défaut, `main` ;
- `provider=claude` et `model=claude-sonnet-5-5` : le brouillon s'ouvre en Sonnet 5.5, pour préserver le quota Claude Pro des associés.

Un lien n'envoie rien : il ouvre un brouillon que l'associé lit, complète (son prénom) puis envoie. Les liens d'exercice donnent seulement le **point de départ** (la branche, l'installation) et jamais le brief : le brief, c'est l'exercice.

## Comment en créer d'autres

**Depuis T3 Code (le plus simple).**
1. Ouvrez un nouveau thread dans le projet de l'atelier, et choisissez le modèle (Sonnet 5.5 pour un lien destiné aux associés).
2. Écrivez le brouillon dans le composeur, sans l'envoyer.
3. Ouvrez la palette de commandes et choisissez **« Copy prompt link with repo and model »**. Le lien copié contient le brouillon, le dépôt GitHub et le modèle choisi. (**« Copy prompt link »** seul ne copie que le brouillon, sans dépôt ni modèle.)

**À la main.** Un lien a la forme `https://app.t3.codes/new?prompt=…&repo=KatalyxOrg/klass-atelier-agents&provider=claude&model=claude-sonnet-5-5`, avec le texte encodé pour une adresse web (voir la [documentation des prompt links](https://github.com/pingdotgg/t3code/blob/main/docs/user/prompt-links.md)).

**Pour un lien de la page support.** Ajoutez dans `index.html` un emplacement `<p class="prompt-link" data-prompt-link="<clé>"><span class="etiquette">…</span></p>` et, plus loin dans la page, le texte du prompt dans `<pre class="prompt" id="prompt-<clé>">…</pre>`. Puis demandez à l'agent de lancer `node outils/prompt-links/generer.mjs` : il pose le lien dans la page et met à jour la liste ci-dessus. Faites de même après avoir modifié le texte d'un prompt existant.

**Les règles d'un bon lien :**
- 8 000 caractères au plus une fois décodé (la limite de T3 Code) ;
- aucun caractère invisible : T3 Code les retire et prévient l'associé que le texte est peut-être malveillant ;
- un point de départ, jamais le brief d'un exercice ;
- pas de « vérifie ton travail » : on donne des yeux et une grille.

`npm run verifier-atelier -- 7` contrôle les deux premières règles, ainsi que `repo`, `provider` et `model`, sur tous les liens du dépôt.
