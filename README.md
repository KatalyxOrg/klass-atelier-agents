# Klass by Katalyx — Atelier « Faire travailler des agents en confiance »

Le dossier d'exercices du cours. Il s'ouvre dans **T3 Code** : c'est l'agent qui installe, rend et utilise Git pour vous.

- **La page support :** ouvrez `index.html` (ou demandez à votre agent de vous l'ouvrir).
- **La source de vérité :** `sources/`, le client fictif Brûlerie Caravelle, nos offres, nos tarifs et nos références.
- **Les règles de la maison pour l'agent :** `CLAUDE.md`.
- **Les parcours :** `proposition/` et `video/`.
- **Le kit de la charte Klass :** `klass/`.

Pour le formateur : `npm run verifier-atelier` contrôle l'atelier depuis un clone vierge du dépôt distant (voir `outils/verifier-atelier/README.md`).
